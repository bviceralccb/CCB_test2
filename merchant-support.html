QUICK TROUBLESHOOTING

Common terminal questions.

PAX terminals use scheduled restarts to maintain performance. Review the scheduled reboot setting in the terminal’s Security menu and choose a time outside business hours. Chino Commercial Bank notes a maintenance window between 2:00 AM and 4:00 AM.

A missed batch can be caused by a connection problem. Confirm connectivity, then use the terminal application’s batch function to close the batch manually. Contact Merchant Support if the problem continues.

COM ERROR usually indicates that the terminal cannot reach the network. Verify the Wi-Fi or Ethernet connection, reconnect if necessary and run the terminal’s network self-check before retrying the transaction.

Some debit cards or transactions may not permit a standard debit return or void. The bank’s support guidance suggests processing the return through the credit function when appropriate. Contact Merchant Support if you need assistance with a specific transaction.

For complete device instructions and the latest support information, visit the official Merchant Services Support page.
